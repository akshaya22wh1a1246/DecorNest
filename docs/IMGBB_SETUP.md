# 🖼️ ImgBB Image Hosting Setup (FREE - No Billing!)

ImgBB is a free image hosting service. No credit card, no billing, no limits!

---

## 📋 STEP 1: Create ImgBB Account (1 minute)

1. Go to: https://imgbb.com/
2. Click: **"Sign up"** (top right)
3. Enter email & password
4. OR click "Sign up with Google" (easier!)
5. Verify email if asked

---

## 📋 STEP 2: Get API Key (Optional - for bulk upload)

Skip this if uploading manually via website.

1. Go to: https://api.imgbb.com/
2. Click: **"Get API key"**
3. Copy the key (save it)

---

## 📋 STEP 3: Upload Your Images (3 minutes)

### Manual Upload (Easy):

1. Go to: https://imgbb.com/upload
2. Click: **"Start uploading"** button
3. Select your 13 images (Ctrl+A to select all)
4. Click Open
5. Wait for uploads to complete
6. For EACH image:
   - Click the image
   - Find "Direct link" 
   - Click **Copy** button
   - Paste in Notepad

**You'll get URLs like:**
```
https://i.ibb.co/abc123/image1.jpg
https://i.ibb.co/xyz789/image2.jpg
```

---
